# Shortcuts that enable D0t on this iPhone

iOS will not import an unsigned .shortcut from a chat. Build these four in Shortcuts. Names must match.

## 1. D0t Enable

1. Create Folder — D0tSandbox — On My iPhone
2. Create Folder — drop — inside D0tSandbox
3. Create Folder — quarantine — inside D0tSandbox
4. Create Folder — trusted — inside D0tSandbox
5. Create Folder — burn — inside D0tSandbox
6. Create Folder — notes — inside D0tSandbox
7. Text — D0t Sandbox live. Projects stay separate. Hexcore, Tool God, NERVEGRID, PhoenixWrap, HandOfGod, Plug Key, Helixlock, KEEP.
8. Copy to Clipboard
9. Open URL — https://github.com/xxlowcxx/XR-Sandbox/blob/main/phone-sandbox/index.html
10. Open URL — https://grok.com
11. Show Notification — title D0t Enable — body lanes ready. short prompt on clipboard.

## 2. D0t Drop

Share Sheet. Receive Files, Images, Text. Save File to D0tSandbox/drop. Notify.

## 3. D0t Ask

Ask for a short prompt. Ask for the xAI key at run time. POST https://api.x.ai/v1/chat/completions with Authorization Bearer plus the key. Show the message content. Do not hardcode the key. Do not share the shortcut after a run if Shortcuts kept it.

## 4. D0t Presence

Date, format ISO, append to D0tSandbox/notes/presence.txt, notify.

Automation: Charger Connected runs D0t Presence with Ask Before Running ON.
