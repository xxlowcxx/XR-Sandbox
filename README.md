# XR-Sandbox

iPhone XR userspace sandbox. Owner: LowC. Toolaid.

This phone cannot be flashed into a custom OS from chat. This repo is the sandbox that *can* live on the XR today:

- Home Screen web app (`index.html`)
- Shortcuts folder ritual (`SHORTCUT.md`)
- drop / trusted / burn / notes layout (Phoenix-style ingest names)

## Install on this XR

1. Open `index.html` in **Safari** (not in-app browsers).
2. Share → **Add to Home Screen** → name it `XR Sandbox`.
3. Build the Shortcut in `SHORTCUT.md` so `On My iPhone/XR-Sandbox` exists.
4. Optional: Focus mode `XR Lab` — only Files, Safari, Shortcuts, this icon.
